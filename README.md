# Electricity Calculator

## Description

## Version 1 - Original code without input validation
-Input: Accepts student's name, previous meter readings and current meter reading.
-Process: Calculates consumption, total bill and prints them.
-Output: Electricity consumption and total bill.

## Version 2 - Has input validation
-Input:  Accepts student's name, previous meter readings and current meter reading, it has an error message if validation validated.
-Process: Calculates consumption, total bill, checks if validation is validated and prints them if validated.
-Output: Electricity consumption and total bill, Prints an error message if validation is not met.
